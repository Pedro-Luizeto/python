## 📚 Sobre o projeto

Este repositório reúne exemplos e exercícios feitos durante meus estudos de **Python**.  
A ideia é praticar os fundamentos da linguagem e registrar minha evolução, um código de cada vez.

## 🗂️ Organização

| Pasta | Conteúdo |
|---|---|
| `conceitos/` | Exemplos de variáveis, entradas, strings, listas, tuplas, dicionários e condicionais |
| `exercicios/` | Exercícios práticos numerados |

## 🧠 O que estou praticando

- Variáveis e tipos de dados
- Entrada de informações com `input()`
- Operações matemáticas
- Strings e formatação de texto
- Listas, tuplas e dicionários
- Condicionais (`if`, `elif` e `else`)
- Estruturas `match`

## ▶️ Como executar

É necessário ter o **Python 3** instalado. No terminal, execute um arquivo a partir da pasta do repositório:

```bash
python conceitos/variaveis.py
